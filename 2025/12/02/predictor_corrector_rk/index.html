常微分方程求解之预估校正与Runge-Kutta方法

预估校正方法通过结合显式和隐式方法的优点，为求解常微分方程提供了高效且精确的途径。本文将详细推导预估校正方法的基本思想，并自然过渡到经典的Runge-Kutta方法体系。

1. 引言与动机

1.1 核心矛盾

显式方法 vs 隐式方法：

  • 显式方法：易于计算，但精度低、稳定性差
  • 隐式方法：精度高、稳定性好，但每步都需要求解非线性方程

核心问题：能否结合两者优点，既避免隐式求解的复杂性，又提高显式方法的精度？

1.2 预估校正的基本思想

答案：预估-校正 (Predictor-Corrector, P-C) 策略

  1. 预估 (Predict)：用简单的显式方法得到初步估计值 \(y_{n+1}^{(0)}\)
  2. 校正 (Correct)：用该估计值代入隐式公式右端，计算校正值 \(y_{n+1}^{(1)}\)

这样就避免了求解非线性方程，同时提高了精度！

2. 预估-校正方法的构造

2.1 Euler-梯形预估校正法

这是最经典的预估校正组合。

预估步 (Predictor) —— 显式Euler法

\[ y_{n+1}^{(0)} = y_n + h f(x_n, y_n) \]

这一步给出了 \(y_{n+1}\) 的粗略估计。

校正步 (Corrector) —— 梯形法

用预估值 \(y_{n+1}^{(0)}\) 代入梯形公式的右端：

\[ y_{n+1} = y_n + \frac{h}{2}\left[ f(x_n, y_n) + f(x_{n+1}, y_{n+1}^{(0)}) \right] \]

关键观察：现在右端全部都是已知量！

3. 误差分析

3.1 局部截断误差

定理 3.1
Euler-梯形预估校正法的局部截断误差为：

\[ R_{n+1} = -\frac{5h^3}{12} y'''(\xi) + O(h^4), \quad \xi \in (x_n, x_{n+1}) \]

即 \(R_{n+1} = O(h^3)\)，因此该方法具有 2阶精度。

证明：

符号约定：设 \(y_n = y(x_n)\)（假设第 \(n\) 步是精确的），则对精确解 \(y(x)\) 在 \(x_n\) 处Taylor展开：

\[ y(x_{n+1}) = y(x_n) + h y'(x_n) + \frac{h^2}{2} y''(x_n) + \frac{h^3}{6} y'''(x_n) + O(h^4) \]

预估步（显式Euler）：

\[ y_{n+1}^{(0)} = y_n + h f(x_n, y_n) = y(x_n) + h y'(x_n) \]

与精确解比较：

\[ y(x_{n+1}) - y_{n+1}^{(0)} = \frac{h^2}{2} y''(x_n) + \frac{h^3}{6} y'''(x_n) + O(h^4) \]

校正步（梯形法）：

\[ y_{n+1} = y_n + \frac{h}{2}[f(x_n, y_n) + f(x_{n+1}, y_{n+1}^{(0)})] \]

对 \(f(x_{n+1}, y_{n+1}^{(0)})\) 进行Taylor展开：

\[ f(x_{n+1}, y_{n+1}^{(0)}) = f(x_{n+1}, y(x_{n+1})) - f_y \cdot [y(x_{n+1}) - y_{n+1}^{(0)}] + O(h^4) \]

💡 为什么误差项是 O(h⁴)？（点击展开）

对二元函数 \(f(x, y)\) 关于 \(y\) 在点 \((x_{n+1}, y(x_{n+1}))\) 处进行Taylor展开：

\[ f(x_{n+1}, y_{n+1}^{(0)}) = f(x_{n+1}, y(x_{n+1})) + f_y \cdot [y_{n+1}^{(0)} - y(x_{n+1})] + \frac{1}{2}f_{yy} \cdot [y_{n+1}^{(0)} - y(x_{n+1})]^2 + \cdots \]

由于 \(y_{n+1}^{(0)}\) 是Euler法预估值，其误差为 \(O(h^2)\)：

\[ y(x_{n+1}) - y_{n+1}^{(0)} = \frac{h^2}{2}y''(x_n) + O(h^3) \]

因此：

  • 一阶项：\(f_y \cdot O(h^2) = O(h^2)\)
  • 二阶项：\(\frac{1}{2}f_{yy} \cdot [O(h^2)]^2 = O(h^4)\)

即高阶项从 \(O(h^4)\) 开始，故可合并写成上述形式。

代入预估误差：

\[ f(x_{n+1}, y_{n+1}^{(0)}) = y'(x_{n+1}) - f_y \cdot \left(\frac{h^2}{2} y''(x_n) + O(h^3)\right) + O(h^4) \]

\[ = y'(x_{n+1}) - \frac{h^2}{2} f_y y''(x_n) + O(h^3) \]

代入校正公式：

\[ y_{n+1} = y(x_n) + \frac{h}{2}\left[ y'(x_n) + y'(x_{n+1}) - \frac{h^2}{2} f_y y''(x_n) \right] + O(h^4) \]

利用 \(y'(x_{n+1}) = y'(x_n) + h y''(x_n) + \frac{h^2}{2} y'''(x_n) + O(h^3)\)：

\[ y_{n+1} = y(x_n) + h y'(x_n) + \frac{h^2}{2} y''(x_n) + \frac{h^3}{4} y'''(x_n) - \frac{h^3}{4} f_y y''(x_n) + O(h^4) \]

而精确解在 \(x_n\) 处的标准Taylor展开为：

\[ y(x_{n+1}) = y(x_n) + h y'(x_n) + \frac{h^2}{2} y''(x_n) + \frac{h^3}{6} y'''(x_n) + O(h^4) \]

两式相减得到局部截断误差：

\[ R_{n+1} = y(x_{n+1}) - y_{n+1} = \left(\frac{1}{6} - \frac{1}{4}\right)h^3 y'''(x_n) + \frac{h^3}{4} f_y y''(x_n) + O(h^4) \]

\[ = -\frac{h^3}{12} y'''(x_n) + O(h^4) \]

因此，局部截断误差为：

\[ \boxed{R_{n+1} = -\frac{h^3}{12} y'''(x_n) + O(h^4) = O(h^3)} \]

结论：预估校正法保持了 2阶精度（局部误差 \(O(h^3)\)，整体误差 \(O(h^2)\)）。 \(\square\)

3.2 整体误差

类似梯形法的推导，可以证明：

\[ |y(x_n) - y_n| \leq K h^2 \]

即整体误差为 \(O(h^2)\)，方法是 2阶收敛的。

3.3 与纯梯形法的比较

特性 纯梯形法 Euler-梯形P-C
精度阶数 2阶 2阶
每步计算 需迭代求解非线性方程 仅需2次函数评估
稳定性 A-稳定 稳定性略差（非A-稳定）
计算效率 低（迭代） 高（显式）

结论：P-C方法通过牺牲少量稳定性，换取了显式计算的便利性和高效率。

4. 从预估校正到Runge-Kutta方法

4.1 核心思想的演化

预估校正方法启发我们：

核心思想：通过在区间内多次评估函数 \(f(x,y)\)，并巧妙地组合这些值，可以构造出高精度的数值格式。

Runge-Kutta (RK) 方法将这一思想系统化：

  • 不依赖以往时刻的信息（单步法）
  • 通过在区间内的多个中间点评估函数
  • 用这些值的加权平均来更新解

4.2 二阶Runge-Kutta方法 (RK2)

一般形式

\[ \begin{cases} k_1 = f(x_n, y_n) \\ k_2 = f(x_n + \alpha h, y_n + \beta h k_1) \\ y_{n+1} = y_n + h(a_1 k_1 + a_2 k_2) \end{cases} \]

目标：选择参数 \(\alpha, \beta, a_1, a_2\) 使得方法达到2阶精度。

Taylor匹配

符号约定：设第 \(n\) 步精确（\(y_n = y(x_n)\)），对精确解 \(y(x)\) 进行Taylor展开。

对精确解展开：

\[ y(x_{n+1}) = y(x_n) + h y'(x_n) + \frac{h^2}{2} y''(x_n) + O(h^3) \]

利用链式法则计算二阶导数：

\[ y''(x_n) = \frac{df}{dx}\bigg|_{x_n} = f_x + f_y \cdot f \]

代入：

\[ y(x_{n+1}) = y(x_n) + h f(x_n, y_n) + \frac{h^2}{2}[f_x + f_y \cdot f] + O(h^3) \]

对 \(k_2\) 进行Taylor展开。利用二元函数的一阶Taylor展开公式：

\[ f(x_0 + \Delta x, y_0 + \Delta y) = f(x_0, y_0) + f_x(x_0, y_0) \Delta x + f_y(x_0, y_0) \Delta y + O(\Delta^2) \]

其中 \(\Delta^2\) 表示 \(\Delta x^2, \Delta y^2, \Delta x \Delta y\) 等二阶项。

对于 \(k_2 = f(x_n + \alpha h, y_n + \beta h k_1)\)（注意 \(k_1 = f(x_n, y_n)\)），有：

\[ k_2 = f(x_n + \alpha h, y_n + \beta h k_1) \]

\[ = f(x_n, y_n) + \alpha h f_x(x_n, y_n) + \beta h k_1 f_y(x_n, y_n) + O(h^2) \]

\[ = f(x_n, y_n) + \alpha h f_x(x_n, y_n) + \beta h f(x_n, y_n) f_y(x_n, y_n) + O(h^2) \]

代入RK2公式：

\[ y_{n+1} = y_n + h(a_1 k_1 + a_2 k_2) \]

\[ = y(x_n) + h\Big(a_1 f(x_n, y_n) + a_2 [f(x_n, y_n) + \alpha h f_x(x_n, y_n) + \beta h f(x_n, y_n) f_y(x_n, y_n)]\Big) + O(h^3) \]

\[ = y(x_n) + h(a_1 + a_2) f(x_n, y_n) + h^2 a_2[\alpha f_x(x_n, y_n) + \beta f(x_n, y_n) f_y(x_n, y_n)] + O(h^3) \]

与Taylor展开比较系数：

\[ \begin{cases} a_1 + a_2 = 1 \\ a_2 \alpha = \frac{1}{2} \\ a_2 \beta = \frac{1}{2} \end{cases} \]

3个方程，4个未知数 → 有一族解！

常见的RK2方法

1. 改进Euler法（Heun方法）

取 \(\alpha = \beta = 1, a_1 = a_2 = \frac{1}{2}\)：

\[ \boxed{ \begin{cases} k_1 = f(x_n, y_n) \\ k_2 = f(x_n + h, y_n + h k_1) \\ y_{n+1} = y_n + \frac{h}{2}(k_1 + k_2) \end{cases} } \]

几何意义：在区间起点和终点各计算一次斜率，取平均值。

2. 中点法

取 \(\alpha = \beta = \frac{1}{2}, a_1 = 0, a_2 = 1\)：

\[ \boxed{ \begin{cases} k_1 = f(x_n, y_n) \\ k_2 = f\left(x_n + \frac{h}{2}, y_n + \frac{h}{2} k_1\right) \\ y_{n+1} = y_n + h k_2 \end{cases} } \]

几何意义：用区间中点的斜率代表整个区间。

RK2与预估校正的关系

注意到改进Euler法(Heun)与Euler-梯形P-C形式非常相似！

改进Euler法 (Heun RK2)：

\[ \begin{cases} k_1 = f(x_n, y_n) \\ k_2 = f(x_n + h, y_n + h k_1) \\ y_{n+1} = y_n + \frac{h}{2}(k_1 + k_2) \end{cases} \]

Euler-梯形预估校正法：

\[ \begin{cases} \text{预估: } y_{n+1}^{(0)} = y_n + h f(x_n, y_n) \\ \text{校正: } y_{n+1} = y_n + \frac{h}{2}[f(x_n, y_n) + f(x_{n+1}, y_{n+1}^{(0)})] \end{cases} \]

对比分析：

步骤 Heun RK2 Euler-梯形P-C
第1步 计算起点斜率：\(k_1 = f(x_n, y_n)\) 预估：\(y_{n+1}^{(0)} = y_n + h f(x_n, y_n)\)
第2步 用 \(k_1\) 推进到终点，计算 \(k_2 = f(x_n + h, y_n + h k_1)\) 计算预估值处的斜率：\(f(x_{n+1}, y_{n+1}^{(0)})\)
第3步 取平均：\(y_{n+1} = y_n + \frac{h}{2}(k_1 + k_2)\) 校正：\(y_{n+1} = y_n + \frac{h}{2}[f(x_n, y_n) + f(x_{n+1}, y_{n+1}^{(0)})]\)

关键观察： - Heun的 \(k_1\) 就是 \(f(x_n, y_n)\) - Heun的 \(y_n + hk_1\) 就是P-C的预估值 \(y_{n+1}^{(0)}\) - Heun的 \(k_2\) 就是 \(f(x_{n+1}, y_{n+1}^{(0)})\)

它们本质上是同一个方法的不同视角！

5. 经典四阶Runge-Kutta方法 (RK4)

5.1 公式

这是最广泛使用的ODE求解器之一：

\[ \boxed{ \begin{cases} k_1 = f(x_n, y_n) \\ k_2 = f\left(x_n + \frac{h}{2}, y_n + \frac{h}{2} k_1\right) \\ k_3 = f\left(x_n + \frac{h}{2}, y_n + \frac{h}{2} k_2\right) \\ k_4 = f(x_n + h, y_n + h k_3) \\ y_{n+1} = y_n + \frac{h}{6}(k_1 + 2k_2 + 2k_3 + k_4) \end{cases} } \]

5.2 精度分析

定理 5.1
经典RK4方法的局部截断误差为：

\[ R_{n+1} = O(h^5) \]

因此整体误差为 \(O(h^4)\)，是 4阶方法。

证明思路：通过Taylor展开匹配 \(y(x_{n+1})\) 的前5项，系数矩阵有11个方程，经典RK4选择了一组特别简洁的解。（完整推导涉及大量代数，此处省略）

5.3 计算效率

方法 精度阶 每步函数评估 总计算量 (达到同样精度)
Euler 1阶 1次 \(O(h^{-1})\)
梯形/RK2 2阶 2次 \(O(h^{-1/2})\)
RK4 4阶 4次 \(O(h^{-1/4})\)

实际意义：若要精度提高10倍，RK4只需步长缩小 \(10^{1/4} \approx 1.78\) 倍，而Euler需要10倍！

6. 稳定性分析

6.1 测试方程

对于 \(y' = \lambda y\)，令 \(z = h\lambda\)，各方法的增长因子为：

方法 增长因子 \(G(z)\)
显式Euler \(1 + z\)
RK2 (Heun) \(1 + z + \frac{z^2}{2}\)
RK4 \(1 + z + \frac{z^2}{2} + \frac{z^3}{6} + \frac{z^4}{24}\)
精确解 \(e^z\)

观察：RK4的增长因子是 \(e^z\) 的前5项Taylor展开，这正是它4阶精度的根源！

6.2 稳定域

要求 \(|G(z)| \leq 1\)：

  • RK2: \(|1 + z + \frac{z^2}{2}| \leq 1\) → 稳定域约为 \(z \in [-2, 0]\)
  • RK4: \(|1 + z + \frac{z^2}{2} + \frac{z^3}{6} + \frac{z^4}{24}| \leq 1\) → 稳定域约为 \(z \in [-2.78, 0]\)

结论：

  • RK方法都是条件稳定的（非A-稳定）
  • 高阶RK方法稳定域更大，但仍需步长限制
  • 对于刚性问题，应使用隐式RK方法（超出本文范围）
